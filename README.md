# 画室 · 学员档案与画材库存

画室业务管理系统：以「学员档案」为主，串起课程排期与画材领用两条从线，画材独立台账。靛青主题、顶部标签页导航、学员列表双击行打开右侧抽屉查看档案与排课。

## 启停

```bash
sh start.sh     # 构建并启动（mysql / backend / frontend）
sh stop.sh      # 停止
sh clean.sh     # 停止并清理数据卷
```

## 验收（课后成果记录闭环）

```bash
sh start.sh
node acceptance/acceptance.mjs    # 覆盖正常提交/取消课次/重复提交/并发提交/学员删除与状态变化
node acceptance/acceptance-schedule.mjs  # 排课取消与重排状态闭环：正常取消后重排/边界相邻时段/
                                         # 重复取消/并发取消与排课/已上课不可取消/取消后查看历史
```

## 模块

- 学员档案：学号唯一、手机号校验、级别（少儿/成人/艺考）、状态（在读/休学/结业）；有排课/记录/领用历史时删除被拦截
- 画材库存：名称唯一、库存≥0、类别（颜料/画笔/画布/工具）、停用不可领用
- 课程排期：依赖学员（在读才能排课）、同日期时段不重叠（仅待上课/已上课占位）、待上课可取消/签到；
  已取消记录保留供历史查看但立即释放时段可重排；已上课为终态不可取消；并发取消与重排按「学员行→课次行」
  悲观锁串行，按最终状态稳定判定，不会误拦重排或产生两条有效课次
- 领用记录：新建即扣库存、画材须「在库」、库存不足拦截
- 课后成果记录：仅「已上课」课次可建；一课次一份（课次行锁 + schedule_id 唯一索引 + 幂等提交）；
  草稿（可只填点评）→ 已提交（作品主题/完成度/点评必填）→ 已归档（只读）；
  草稿不计入已完成课程；课程详情与学员档案均展示记录当前状态与最后更新时间；
  删除草稿只删记录行，不触碰课次、库存与学员状态
